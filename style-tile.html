Style Tile

This page documents the design system used across this project: the palette, the typographic scale, and the spacing rules, so every page pulls from the same set of decisions instead of improvising fresh choices each time.

Palette

Primary, Forest Green #2f4a3d. Header background and heading color. White text on this background checks at 9.7 to 1, well above the 4.5 to 1 minimum.

Neutral text #262220 on neutral background #f8f5f0. Body text and page background. Checks at 14.5 to 1, the safest pairing in the whole palette.

Accent, Burnt Orange #c1652b. Used only as a background for buttons and small highlights, never as text sitting directly on the page background, since that pairing only checks at 3.7 to 1, below the 4.5 to 1 minimum for normal text.

CTA background, a darker version of the accent, #a8541f. White text on this darker shade checks at 5.3 to 1, comfortably above the minimum instead of sitting right at the edge the way the lighter accent does.

Type Scale

Heading 1, 2.5rem (40px)

Heading 2, 1.75rem (28px)

Heading 3, 1.25rem (20px)

Body text, 1rem (16px)

Spacing

  • main: max-width 800px, centered with margin: 0 auto, padding 40px top and bottom, 20px left and right.
  • Every h2: margin-bottom 8px, keeps a heading close to the paragraph it belongs to.
  • Every p: margin-bottom 32px, separates one topic from the next.
  • The call-to-action button: padding 16px top and bottom, 32px left and right, plus margin-top 24px to separate it from whatever sits above it.

Notice each color swatch has two classes on it, for example class="swatch swatch-primary". An HTML element can carry more than one class at once, separated by a space, and it picks up the CSS rules from every class listed. swatch will hold the shape every color box shares: width, height, rounded corners, spacing. Each of the four modifier classes, swatch-primary, swatch-neutral, swatch-accent, and swatch-cta, will hold just the one background color that makes that box different from the others. This avoids repeating the same width, height, and border-radius four separate times. Add these rules to css/style.css: .swatch { display: inline-block; width: 120px; height: 80px; margin-bottom: 8px; border-radius: 4px; vertical-align: top; } .swatch-primary { background-color: #2f4a3d; } .swatch-neutral { background-color: #262220; } .swatch-accent { background-color: #c1652b; } .swatch-cta { background-color: #a8541f; } .type-sample-h1 { font-size: 2.5rem; } .type-sample-h2 { font-size: 1.75rem; } .type-sample-h3 { font-size: 1.25rem; }
